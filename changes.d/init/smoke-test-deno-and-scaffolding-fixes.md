 -  Fixed the `test` task of Deno projects scaffolded by `fedify init`.
    `deno test` denied the permissions the smoke test needs and reported
    success even when the smoke test failed, because the script relied on
    `process.exitCode` without registering a `Deno.test()`.  The task now
    grants only the run, env, and net permissions the smoke test uses, and the
    Deno smoke-test script registers a `Deno.test()` that fails the run and
    stops the dev server when the test process is interrupted.  The
    smoke-test script also reports when the dev server could not be spawned
    instead of timing out while waiting for a port.
 -  Fixed Hono projects scaffolded by `fedify init` so that *src/app.ts* and
    *src/index.ts* no longer start with a leaked `// @ts-nocheck` template
    comment that disabled type checking.
 -  Fixed `fedify init --skip-install` for Astro projects on Deno and for
    SvelteKit projects, whose scaffolders installed dependencies regardless of
    the option.
 -  Fixed the Deno *deno.json* generated by `fedify init` for the bare-bones
    template, which configured `hono/jsx` compiler options without depending
    on Hono.
 -  Changed the `@types/express` version installed by `fedify init` to `^5.0.6`
    so that it matches the Express 5 package it accompanies, and updated the
    other third-party dependency versions used by the generated projects.
 -  Changed the minimum Node.js version required to run `@fedify/init` to
    22.0.0, because the package already used `Array.fromAsync()`.
